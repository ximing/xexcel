# M3a 浏览器验收（浏览器）

前置：`pnpm --filter ./apps/demo dev` 启动（仓库根）；dev 下 `window.__xcell` 为 EditorView。
读 raw：`__xcell.state.activeSheet.getCell(r,c)?.raw`（0-based）；显示值目测网格。
每步后附【预期】。失败即终止并回报。

## 1. 新函数
- 清空 demo 数据：A1 输入 `1`，A2 `2`，A3 `3`，A4 输入 `=SUMIF(A1:A3,">1")`
- 【预期】A4 显示 5
- B1 输入 `=IFERROR(1/0,"err")`，B2 输入 `=CONCAT("a",1,"b")`，B3 输入 `=LEFT("excel",2)`
- 【预期】B1 `err`、B2 `a1b`、B3 `ex`

## 2. 日期函数与 TODAY 自动格式
- C1 输入 `=TODAY()`，C2 输入 `=DATE(2026,7,31)`，C3 输入 `=MONTH(C2)`
- 【预期】C1 显示当天日期（yyyy/m/d 格式而非数字）；C2 显示数字 serial；C3 显示 7
- 读 C1 raw：`=TODAY()`；style.numFmt 为 `yyyy/m/d`

## 3. 隐式交集
- E1 输入 `10`，E2 `20`，E3 `30`；F2 输入 `=E1:E3`
- 【预期】F2 显示 20
- F5 输入 `=E1:E3` → 显示 `#VALUE!`
- undo 一次清掉 F5
- 【验收记录】PASS。注意 `#VALUE!` 文本含字母 A，§7 查找 `a` 时该格会按显示文本命中（raw 不含则不参与替换）——预期行为

## 4. 隐藏行列
- 点行头 2（选中整行）→ 工具栏「隐行」
- 【预期】第 2 行消失，行号 1 直连 3，行头边界有双线标记
- Ctrl+A → 「取消隐」→ 第 2 行恢复；Ctrl+Z 撤销取消隐藏 → 又隐藏
- 点列头 B → 「隐列」→ B 列消失；方向键从 A1 按 → 焦点跳到 C1（跳过隐藏列）
- 「取消隐」恢复

## 5. 排序
- 造数据：G1 `name` H1 `score`；G2 `c` H2 `1`；G3 `a` H3 `3`；G4 `b` H4 `2`
- 选中 G1:H4 → 工具栏「排序」→ 对话框确认「数据包含表头」已勾 → 主关键字 H 列 降序 → 确定
- 【预期】行序变为 a/3、b/2、c/1（表头不动）
- Ctrl+Z → 恢复原序
- 选中 G2:H4 → 「A↓」快捷升序 → G 列变 a、b、c

## 6. 自动筛选
- 选中 G1:H4（或光标放 G1 回落 usedRange）→ 工具栏「筛」→ G1/H1 右缘出现下拉箭头
- 【验收记录】PASS（用选区启用，覆盖「对选区启用」路径；单格回落 usedRange 路径实现相同按钮逻辑）
- 点 H1 箭头 → 条件 → 数值 `>` 填 `1` → 确定
- 【预期】只剩 a/3、b/2 两行可见；H1 箭头变蓝高亮
- 再点箭头 → 值列表页签 → 勾选掉 `2` → 确定 → 只剩 a/3
- 「清除该列」→ 全部恢复；工具栏「筛」→ 箭头消失

## 7. 查找/替换
- Ctrl+F → 输入 `a` → 显示匹配计数，Enter 逐个跳转（含 Sheet2 若有）
- 勾选「全簿」→ 计数增加（如别表有内容）
- 展开替换：查找 `a` 替换为 `z` → 「全部替换」→ 当前表全部命中格替换
- 【预期】一次 Ctrl+Z 全部恢复
- Esc 关闭查找栏

## 8. 视口回归（P1）
- 滚到表格最底部与最右侧
- 【预期】最后一行完整可见（不被横向滚动条遮挡 12px）；最后一列完整可见
- 合并 B2:C3，冻结首行首列，滚动后目测合并区跨冻结线渲染无残影（人工一瞥）
