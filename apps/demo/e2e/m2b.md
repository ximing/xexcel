# M2b 浏览器验收（浏览器）

前置：`pnpm --filter ./apps/demo dev`（仓库根）；dev 下 `window.__xcell` 为 EditorView。
读 raw：`__xcell.state.activeSheet.getCell(r,c)?.raw`；显示值目测网格。
每节附【预期】。失败即终止并回报。先 Ctrl+A / Delete 清空 demo 数据再开始。

## 1. 数字格式
- A1 输入 `1234.5` → 点「,」→ 显示 `1,234.50`；点「%」→ 显示 `123450%`；A2 输入 `0.5` → 点「%」→ `50%`
- A3 输入 `99` → 点「¥」→ `¥99.00`；对 A3 点两次「.0+」→ `¥99.0000`
- 【预期】raw 不变（A1 raw 仍 `1234.5`）；undo 逐步回退格式

## 2. 日期
- B1 输入 `2026/7/31` → 显示 `2026/7/31`，raw 为数字 serial
- B2 输入 `=B1+7` → 显示 serial 数字；对 B2 点「,」再目测（数字格式生效）
- B3 输入 `13:30` → 显示 `13:30`，raw 为小数
- 【预期】非法日期 `2026/2/30` 原样显示文本

## 3. 字体
- C1 输入 `标题` → 字号选 24、点 U、点 S → 渲染变大且带下划线+删除线
- 双击第 1 行行头下缘 → 行高自适应到能容下 24px 字
- 【预期】undo 恢复行高与样式

## 4. 合并单元格
- D1:E2 区域选 D1 输入 `合并` → 选 D1:E2 点「合」（无多值不弹确认）→ 单一大格显示
- 点 E2（被吞格）→ 选区为整个 D1:E2；双击 → 编辑器开在 D1
- 【预期】点「拆」→ 恢复四格；undo 合并 → `合并` 字样回到 D1 且区域恢复

## 5. 插入/删除行列（公式级联）
- F5 输入 `100`，F1 输入 `=F5*2`
- 选第 5 行整行 → 点「+行」→ F1 公式变 `=F6*2`（值 200 不变）；「-行」→ 恢复 `=F5*2`
- 选第 5 行整行 → 点「-行」→ F1 显示 `#REF!`，raw `=#REF!*2`
- 【预期】Ctrl+Z → 公式原文 `=F5*2` 与 F5 的值一并恢复

## 6. 冻结行列
- 滚动到下方后点「冻行」「冻列」→ 首行首列恒显，分割线可见
- 继续滚动 → 冻结区不动；点 A1 下方单元格编辑 → 编辑框位置正确
- 【预期】「解冻」恢复；行列头命中/选区/填充柄在冻结下均正确

## 7. 自适应与重置
- G1 输入一长串文字 → 双击 G 列头右缘 → 列宽刚好容下
- 选中 G 整列 → 点「重置」→ 恢复默认宽
- 【预期】空列双击 → 恢复默认宽

## 8. 滚动条
- 拖纵向滑块到底 → 命中最后一行区域；点轨道 → 翻页
- 横向同理；滚轮行为与拖拽结果一致（scrollX/Y 钳位不溢出）
- 【预期】内容不足一屏的方向无滑块

## 9. tabbar 快速连点（P1 回归）
- 以脚本方式快速连点「+」5 次（同步循环）
- 【预期】新增 5 张表（修复前会丢）
