# M3b 浏览器验收（浏览器）

前置：`npm run dev` 启动；dev 下 `window.__xcell` 为 EditorView。
读 raw：`__xcell.state.activeSheet.getCell(r,c)?.raw`（0-based）；style：`...?.style`。每步后附【预期】。失败即终止并回报。

## 1. 边框
- 选 A1:B2 → 工具栏「框」→ 全框（细线黑）→ 【预期】四格外框+内十字可见
- 读 A1 style.border：top/right/bottom/left 均 {style:'thin'}
- 选 B2:C3 → 外框（粗线红）→ 【预期】A1:B2 的右/下内边变粗红（共享边权重 3 压 1）
- Ctrl+Z ×2 → 边框消失

## 2. 换行与垂直对齐
- A1 输入长文本（>列宽 3 倍）→ 「换行」→ 【预期】行 1 自动撑高、文本多行完整可见
- 读 A1 style.wrap === true
- 「上」→ 文本贴顶；「下」→ 贴底
- 拖行 1 下缘手动调高 → 改文本 → 【预期】行高不再随内容变化（手动优先）
- Ctrl+Z 撤销全部

## 3. 格式刷
- A1 设粗体+黄底+边框全框 → 选 A1 → 单击「刷」→ 点 C3 → 【预期】C3 粗体黄底有框，刷子自动解除
- 选 A1 → 双击「刷」→ 连点 C4、C5 → 两格同格式；Esc → 刷子解除（工具栏「刷」不再高亮）
- Ctrl+Z 逐步撤销

## 4. 条件格式
- A1:A5 填 5,15,25,15,x → 「条件」→ 添加值规则 >10 红底（范围 A1:A5）→ 确定
- 【预期】A2/A3/A4 红底
- 再开对话框添加重复值规则绿字 → 【预期】A2/A4 绿字（重复 15）
- 调整两规则顺序（值规则后移）→ 若样式键不冲突各自生效
- 删第 2 行 → 【预期】规则 range remap（读 condFormats 确认 er 减 1）；Ctrl+Z 恢复
- 对话框取消不生效；确定后一次 Ctrl+Z 全撤

## 5. 标签拖动
- 新建 Sheet2、Sheet3 → 拖 Sheet3 到最前（指示线可见）→ 【预期】顺序 Sheet3,Sheet1,Sheet2
- Ctrl+Z → 顺序还原；单击 Sheet1 切表不受拖拽影响

## 6. 右键菜单
- 单元格右键（选区外）→ 【预期】选区先跳到该格，菜单含剪切/复制/粘贴/插入行列/删除行列/隐藏/取消隐藏/清除内容
- 行头右键 → 仅行操作四项；列头右键 → 列版本；标签右键 → 新建/重命名/删除/左移/右移
- 无隐藏项时「取消隐藏」禁用；Esc 关闭；遮罩点击关闭
- 执行「插入行」→ 行插入且一次 Ctrl+Z 撤销

## 7. 缩放
- Ctrl+滚轮上 → 【预期】放大一档（状态栏 110%→125%），光标下内容位置不动
- 滚到 200% 后不再放大；缩回 50% 不再缩小
- 状态栏点 150% → 立即生效；表头/边框/文字均按比例清晰放大
- 150% 下双击编辑格 → 编辑框位置与字号正确；提交后显示正确
- 切表 → 新表 100%；切回 → 仍为 150%（每表独立）

## 8. minor 回归
- 查找 `a` 替换为 `ab` 单格替换 → 【预期】替换后跳到下一匹配（不反复替换同格）
- SortDialog/FindBar 按 Esc 关闭；FindBar 聚焦时 Ctrl+F 不弹浏览器查找
- 双滚动条场景：滑块不越出轨道；点轨道翻页后末行不被遮挡
- 隐藏行 1（首行）→ 行头 1/2 边界有双线标记
