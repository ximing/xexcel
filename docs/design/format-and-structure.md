# 格式和表结构

2023-12

## 数字和日期

`CellStyle.numFmt` 用 numfmt。输入日期时间先收成 Excel 序列值再存，显示交给格式串。

## 字体

族、字号、下划线、删除线进 `CellStyle`，画布按样式画。颜色和粗斜体 M1 就有。

## 合并

合并存在 `SheetData.merges`。渲染、命中、选区、方向键、剪贴板都以锚格为准。拆分是逆操作。

## 插删行列

插删要同时：

- 挪单元格
- 改合并、冻结、隐藏、筛选范围
- 公式引用级联，删掉的变成 `#REF!`

undo 用结构快照，不能只 invert 单元格。冻结窗格在结构变化后要 clamp，别指到表外。

## 冻结

geometry 按冻结行/列切四个象限。滚动只滚解冻区。命中测试和选区绘制跟同一套偏移，不然对不齐。

## 滚动条和自适应

滚动条自己画，拖块、点轨道翻页。行高列宽可以拖，双击边线按内容估一个宽度/高度。
