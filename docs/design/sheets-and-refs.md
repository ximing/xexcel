# 多表和引用

2023-11

M1 的 Workbook 已经是多表，这里补真正能用的那几件事：引用语法、表级 Step、标签栏。

## 引用

lexer/parser 要认：

- `$A$1`、`$A1`、`A$1`
- `Sheet2!B3`，表名带空格或特殊字符时 `'Data 1'!A1`
- 填充分、剪贴板粘贴时对相对引用做 `shiftFormula`，绝对部分不动
- 删行删列把受影响的引用收成 `#REF!`

跨表求值走 `resolveSheet`，找不到表就是 `#REF!`。

## 表操作

Step：插入、删除、改名、切换活动表。删到只剩一张时拒绝。删的是当前表，活动表挪到旁边那张。

undo 要能把表结构和单元格一起回来，别只还单元格。

## 标签栏

React 里做。点选切换、双击改名、加号新增、中间键或菜单删除。后来又加了拖动排序（`MoveSheetStep`）。
