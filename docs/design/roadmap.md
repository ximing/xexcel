# 功能范围

2023 年底内核能用之后列的一张单子，后来按块做完了。没做的（协作、图表、完整函数库）现在也不打算做，见 README。

## 公式

- `$A$1` / `$A1` / `A$1`
- 填充、复制时相对引用跟着走
- `Sheet2!A1`
- 逻辑 / 文本 / 条件聚合 / 日期，常用的那些
- 函数参数里的区域；格子里写区域时按隐式交叉取值

## 样式和结构

- 数字格式、日期序列值
- 字体、字号、下划线、删除线
- 边框、自动换行、垂直对齐、格式刷
- 合并、冻结、插删行列、隐藏、行高列宽、双击自适应

## 多表

标签栏增删改名切换，拖动排序。显示名和内部 id 分开，名字按 Excel 那套限制来。

## 数据

排序（单列、多键）、自动筛选、查找替换、条件格式、数据验证。

## 编辑

右键菜单、Ctrl 多区域、拖动移动、剪贴板带公式和样式、公式栏引用高亮。

## 文件

CSV、xlsx（exceljs）、localStorage 自动保存。xlsx 是整本替换，不是往当前表里拼。
