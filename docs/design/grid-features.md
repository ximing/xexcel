# 数据功能和画布交互

2024

这一块比较杂，都是表格里「用起来才像 Excel」的东西。实现时按能独立合入的小步切。

## 函数和隐式交叉

补了一批逻辑、文本、条件聚合、日期函数。条件（`SUMIF` 这类）跟筛选共用一套 criteria。

格子里写了区域、求值位置又是标量时，按 Excel 的隐式交叉取对应行/列上的值，而不是把区域丢进普通算术。

## 隐藏、排序、筛选、查找

隐藏行/列是 Step。geometry 把高度/宽度当 0，键盘导航跳过，表头有标记。插删行列的 undo 要把隐藏位一起还原。

排序按求值结果，有快速排序和多键。清下方旧值时要明确到底清哪些格，单测里钉过一次。

筛选：值列表 + 条件。隐藏行是派生出来的，不是再存一份。画布上把筛掉的行叠掉。

查找替换跨表，全部替换进同一个事务，方便一次撤销。替换只动文本片段，不再走引用偏移那条分支（试过，容易把公式改坏）。

## 边框、换行、格式刷、条件格式

边框 8 种线型、若干预设。相邻格共用边时按权重决胜。预设只覆盖声明的那几条边，没点到的边保持原样。

换行后行高可以按内容撑开，编辑框挂上之后要再量一次 `scrollHeight`，否则第一帧是瘪的。

格式刷：点一下刷一次，双击锁定。整格样式替换，不是跟目标样式 merge。

条件格式：值、文本、重复项。渲染时算，不写回单元格。文档里可以带颜色，React 侧有一套映射。

## 缩放、右键、标签拖动

缩放 50%–200%，Ctrl+滚轮，锚在指针位置。拖列宽行高的位移要跟缩放一致，改缩放时滚动位置 clamp 一下。

右键菜单按点到的区域出不同项（格子、表头、标签）。菜单在的时候不要让左键那套拖选用 mousemove 接着改选区。

标签拖动排序带插入指示，拖出栏外取消。
