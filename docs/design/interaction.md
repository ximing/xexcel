# 选择、拖动、剪贴板、公式编辑

2024 年中

## 多区域

Ctrl/Cmd 点选、拖选追加区域。`ranges` 数组，活动格必须落在最后一段里。取消某一段时如果活动格不在新的 last range 里，要改活动格，不能还指着已经没选的格子。

## 拖动移动

按住选区边框拖。落点重叠、跨合并格要拒绝并给提示。走事务，撤销一次回到拖之前。

## 剪贴板

内部 payload 带公式和样式，不是只贴显示文本。粘贴时公式按位移偏移。复制后可以反复贴；剪切贴完清源，源和目标重叠时不要把源先清掉。系统剪贴板仍写 TSV，外面贴进来当纯文本。

## 公式编辑

编辑时引用高亮。点画布里的格子可以往公式里插引用。活动格边框和公式栏要同一份状态，避免画布和公式栏各开一个编辑器。
