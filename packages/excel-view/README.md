# @xexcel/view

Imperative Konva canvas for [xexcel](https://github.com/ximing/xexcel). Virtualized grid plus built-in plugins (selection, keymap, clipboard, fill handle, drag-move).

Peer: `@xexcel/core`. Most hosts should use [`@xexcel/react`](https://www.npmjs.com/package/@xexcel/react) instead of mounting `EditorView` by hand.
